## 系统要求

- **操作系统**：Windows 10 / Windows 11（64位）
- **运行时**：无需额外安装，WebView2 随系统自带
- **磁盘空间**：约 200MB（含运行缓存）
- **AI 功能**：需用户自行配置 API Key（DeepSeek / 智谱 / 硅基流动 / Ollama 等）

## 产品简介

BISU 笔溯是一款 100% 本地离线的网文创作桌面工具，专为网文新手作者设计：

- **100% 本地离线**：所有数据存储在本地加密数据库，不上传任何服务器
- **AI 调用走用户自接 API Key**：Key 经 Argon2id 派生 + AES-256-GCM 本地加密
- **不收集任何用户数据**：正文与设定不上传 BISU 任何服务器
- **全流程创作覆盖**：从灵感、大纲、人设到章节写作、质检、发布一站式

## v0.10.7 更新内容（2026-09-27）

> 本版聚焦深度修复与基础设施增强——视频分镜产物持久化、镜级精修流程管理、数据采集闭环、轮询性能优化与仓库卫生清理五大方向。

### 一、视频分镜产物持久化

- **分镜生成产物不再丢失**：视频制作中生成的分镜图、配音、视频片段从纯内存状态改为本地数据库持久化，页面刷新或切换后可恢复，无需重新生成
- **按分镜编号管理**：每个分镜的图片/音频/视频产物独立存储，支持按视频项目查询和清理
- **数据库版本升级**：新增分镜产物表（v54 迁移），含唯一约束支持重复生成时自动覆盖

### 二、镜级精修流程管理

- **五态精修流程**：分镜卡新增「草稿 → 精修中 → 已精修 → 已定稿 → 已发布」五态流转，每个分镜的精修进度可跟踪
- **流转校验**：禁止跳态操作（如草稿不能直接到已定稿），支持合理回退（如精修中可退回草稿）
- **项目级统计**：可查看项目下各分镜在五个状态中的分布数量，精修进度一目了然
- **兼容旧数据**：历史分镜卡自动识别为「草稿」状态，不影响已有内容

### 三、数据采集闭环

- **关键行为事件采集**：支付订单创建、视频生成启动等关键节点自动记录事件，便于后续分析用户行为漏斗
- **本地内存环形缓冲**：事件仅存储在本地内存（容量 1024 条，超出自动覆盖最旧），不发起任何网络请求，不影响隐私
- **调试导出接口**：开发者可通过命令拉取事件用于功能验证，普通用户无感知

### 四、轮询性能优化

- **统一轮询管理**：新增统一轮询工具，支持页面失焦时自动暂停、恢复后继续，减少后台无效请求
- **退避策略**：轮询失败后间隔自动翻倍，避免连续失败时的资源浪费
- **现有轮询保护**：视频制作页 5 处任务轮询均已具备页面失焦暂停能力，后台运行时不消耗多余资源

### 五、仓库卫生清理

- **清理临时脚本**：删除 10 个版本迭代过程中产生的一次性临时修复脚本
- **归档旧版本脚本**：19 个历史版本部署脚本归档到独立目录，主目录更整洁

## 核心功能

### 爆款智能体蜂群
一个项目一组各有人格的智能体，围绕同一本书共享世界设定，7 角色流水线协同产出章节初稿：选题策划 → 人设主笔 → 章节扩写 → 爽点节奏评审 → 质检 → 去 AI 味润色 → 平台合规审校。

### 全流程创作工具
- **长篇连载 / 短篇合集**：多项目管理，章节状态跟踪
- **世界观 / 角色管理 / 大纲管理**：设定一致性校验，跨章人设守卫
- **AI 创作助手**：智能续写、节奏分析、去 AI 味精修、敏感词合规检测
- **质量门控**：4 维评分（去AI味 / 爽点密度 / 情绪曲线 / 逻辑自洽），13 子项明细

### IP 改编链
从小说到剧本、条漫、视频的一站式改编管线：改编规划、分段流水线、剧本工坊、条漫工坊、视频制作、成片驾驶舱。

### 数据与市场
- **多平台排行榜**：番茄 / 起点 / 晋江 / 飞卢等平台榜单趋势
- **写作统计与目标**：字数热力图、创作目标、打卡挑战
- **变现台账**：记录各改编方向投入产出

## 安全与隐私

- 所有创作数据存储于本地 SQLite 数据库，启用 WAL 模式
- API Key 经 Argon2id（64MB 内存 / 3 轮）派生密钥后 AES-256-GCM 加密存储
- 安装包经 minisign 签名，自动更新时验签通过才安装
- 不含任何云依赖，不收集任何用户数据
