# 笔溯 BISU

网文新手作者专属的桌面写作工具。100% 本地离线，正文与设定加密存放在本机，AI 由你自接模型 Key，不上传任何服务器。

## v0.8.0 新了什么

本版分三层能力一次上线。

### 深度创作助手

- 智能续写：按前文与大纲自动往下写，贴合既有文风与节奏。
- 节奏分析：扫描爽点分布与情绪曲线，给出优化建议。
- 人物守卫：跨章核对角色言行与设定，防止人设跑偏。
- 逻辑扫描：揪出剧情矛盾、时间线冲突与漏收伏笔。
- 去 AI 味：把机器腔段落改得更像真人写的。
- 多平台发布：一键适配番茄、起点、晋江等平台格式。
- 爆款公式库：内置可复用的爆款桥段与结构模板。
- 读者模拟：模拟目标读者的阅读反应与弃书点。
- 写作教练：针对当前稿件给出可执行的改进建议。
- 大纲演化：随章节推进反向调整后续大纲。
- 世界观校验、章节时光机、敏感词合规一并上线。

### IP 改编管线

从网文到 IP 的一站式工作台：改编规划、分段流水线、剧本工坊、条漫工坊、视频物料工坊、AI 痕迹消痕报告、变现台账，导航按五大域重组，配套二十余项新操作入口。

### 成片链

导演智能体蜂群自动分工排片，图生视频接入 Kling，批量生成带成本计量与预算熔断，合成管线升级字幕与 BGM 与分辨率，素材台账支持失败恢复，成片驾驶舱一处掌控进度与成本。ffmpeg 随安装包自带，无需另装。

## 安装说明

1. 从上方任一源下载 BISU 安装包。
2. 双击安装包，按提示完成安装。
3. 首次启动设置解锁口令，用于加密本机数据库。
4. 进入设置，填入你自己的大模型 API Key（支持 DeepSeek、智谱、硅基流动、Ollama 等）。
5. 新建项目即可开始写作，所有稿件只保存在本机。

应用内可在设置里检查更新，主源不通时会自动切换到备源。

## 技术特性

- 桌面框架：Tauri 2.1 原生壳，安装包体积小、占用内存低。
- 离线优先：正文与设定全部留在本机，不依赖任何云服务。
- 加密存储：数据库加密存放，API Key 经 Argon2id 派生后用 AES-256-GCM 加密，不明文落盘。
- AI 自带：你用哪家模型的 Key 就走哪家，笔溯不另收 AI 费用。
- 双源更新：GitHub 与 Gitee 双更新通道，主源不可达自动切备源。
- 合成自带：ffmpeg 随安装包分发，视频合成无需单独安装。

## 常见问题

**正文会上传云端吗？**
不会。所有稿件与设定都存在你本机的加密数据库里，AI 调用只与你自己配置的模型端点通信。

**AI 要另外付费吗？**
笔溯不另收 AI 费用。你在设置里填入自己的模型 Key，token 费用由模型厂商按其规则结算。

**换电脑怎么办？**
设置里可一键备份数据库到指定目录，新机器装好同款后从备份恢复即可。

**系统要求？**
Windows 10 或 11 的 64 位版本，无需单独安装运行时。
