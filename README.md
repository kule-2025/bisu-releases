## 产品简介

BISU 笔溯是专为网文新手作者打造的桌面创作工具，直击"写不出、写不快、写不好、发不出"四大痛点：

- **数据完全属于你**：所有作品与设定仅存于你的电脑，断网可用，永不丢失
- **AI 能力自主可控**：接入你自己的大模型账号，想用哪家用哪家，不被平台绑定
- **从灵感到发布一站搞定**：选题、大纲、人设、写作、质检、改编、发布全流程覆盖
- **多角色智能体协同创作**：一组各有人格的 AI 助手围绕你的书协同产出，新手也能稳定输出高质量章节

## 核心功能

### 爆款智能体蜂群
一个项目一组各有人格的智能体，围绕同一本书共享世界设定，7 角色流水线协同产出章节初稿：选题策划 → 人设主笔 → 章节扩写 → 爽点节奏评审 → 质检 → 去 AI 味润色 → 平台合规审校。

### 全流程创作工具
- **长篇连载 / 短篇合集**：多项目管理，章节状态跟踪，正文编辑
- **世界观 / 角色管理 / 大纲管理**：设定一致性校验，跨章人设守卫
- **AI 创作助手**：智能续写、节奏分析、去 AI 味精修、敏感词合规检测
- **质量门控**：4 维评分（去AI味 / 爽点密度 / 情绪曲线 / 逻辑自洽），13 子项明细

### IP 改编链
从小说到剧本、条漫、视频的一站式改编管线：改编规划、分段流水线、剧本工坊、条漫工坊、视频制作、成片驾驶舱。

### 数据与市场
- **多平台排行榜**：番茄 / 起点 / 晋江 / 飞卢等平台榜单趋势
- **写作统计与目标**：字数热力图、创作目标、打卡挑战
- **变现台账**：记录各改编方向投入产出

## 安全与隐私

- 所有创作数据仅存储在你的电脑本地，无需联网即可使用全部核心功能
- 你的大模型密钥仅在本地加密保存，不会上传至任何服务器
- 安装包经过数字签名，自动更新时验证完整性，确保安全可靠
- 不收集任何用户数据，不包含任何云依赖
