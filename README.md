# 笔溯 BISU 网文新手作者专属桌面创作工具

`#网文创作桌面助手` `#爆款小说创作桌面助手` `#爆款网文创作桌面助手` `#网文写作工具` `#桌面写作软件`

> 当前版本：0.9.1（2026-09-24）

笔溯是一款跑在 Windows 桌面的网文写作软件，面向新手作者，从选题、大纲、人设、章节写作到润色发布，把一个人写书需要的工具收拢到同一个本地工作台里。

## 它能做什么

- 网文创作全流程：大纲、人设、世界观、章节写作、润色、发布辅助一站完成。
- 爆款智能体蜂群：多个不同人格的 AI 智能体按选题、主笔、扩写、评审、质检、去 AI 味、合规审校顺序分工，产出可直接发布的章节初稿。
- 项目级知识库：本地知识按项目隔离，千章记忆前情召回，跨项目不串味。
- 多模型聚合：自接多家大模型，按优先级自动衔接与故障转移，写作不中断。
- 深度创作辅助：智能续写、节奏分析、人物一致性守卫、逻辑漏洞扫描、敏感词合规等随稿辅助。
- IP 改编与成片：从网文到剧本、条漫、视频物料的一站式改编管线，配套成片驾驶舱集中查看进度与成本。
- 本地加密存储：项目与稿件加密存于本机，全程离线可用，不联网也能写。

## 本地优先与隐私

- 100% 本地离线，加密存储，不含任何云依赖，不收集任何用户数据。
- AI 调用走用户自接 API Key（DeepSeek / 智谱 / 硅基流动 / Ollama 等），Key 经本地加密保存。
- 你的正文、大纲与设定不上传 BISU 任何服务器。

## 适合谁用

- 想从零开始写网文、但缺一套成体系工具的新手作者。
- 已有存稿、希望用本地工作台把大纲、人设、章节统一管起来的作者。
- 想把作品进一步改编成剧本、条漫或视频物料，需要一站式工作台的作者。
- 在意稿件隐私、不想把正文上传到在线写作平台的作者。

## 变更记录

### v0.9.1（2026-09-24）

本版围绕改编与成片链路做体验与稳定性增强，写作核心功能不变。

- 成片驾驶舱更实用：同一镜头多次生成的结果可并排对比，挑出最满意的一版更直观；成本估算改用真实计费口径，花费一目了然。
- 多视频模型状态可视：视频工坊顶部展示各家视频模型的配置状态，未配置时给出填写引导；网络异常、任务失败、超时等情况都有清楚提示，不再只看到一串技术错误。
- 角色音色可登记：可为不同角色分别记录偏好音色、音调与语速，后续配音按角色套用。
- 条漫导出长条图：条漫分镜可一键纵向拼成长图 PNG，方便预览与分享。
- 蜂群导演台独立页：新增导演台页面，集中查看改编进度、实时运行状态、花费与运行日志。
- 逐镜微调更顺手：分镜可直接上下调换顺序、修改时长，改动后自动标记待重审；成片可在软件内直接播放试听。
- 运行更稳更快：生成任务排队更克制、失败自动重试并退避，长列表与页面切换更流畅，后台空转明显减少。

### v0.9.0（2026-09-24）

本版为大模型配置体验与安全专项更新，写作功能本身无新增。

- 模型管理页面全新布局：AI 模型管理重新排版为服务状态、模型列表、场景默认、密钥用量、高级设置五个区块，操作路径更清晰。
- 模型相关功能命名统一：自动连接、健康检查、模型目录、密钥管理等入口命名规范一致，原有配置平滑兼容。
- 模型配置数据流打通：按写作场景自动匹配当前可用模型，多处读取路径统一为同一份配置，模型失效时自动切换，减少重复加载。
- 配置保存加固：版本更新过程中模型密钥强制写入磁盘，升级后不再丢失已配置的 Key。
- 密钥安全隔离：安装包仅打包必要文件，含明文密钥的配置不会进入安装包与仓库。

### v0.8.0（2026-09-24）

三层能力齐上线：深度创作功能层、IP 全链路层、成片链层。

- 深度创作：智能续写、节奏分析、人物一致性守卫、逻辑漏洞扫描、去 AI 味精修、多平台一键发布、爆款公式库、读者模拟、写作教练、大纲演化、世界观校验、章节时光机、敏感词合规。
- IP 改编：改编规划、分段流水线、剧本工坊、条漫工坊、视频物料工坊、AI 痕迹消痕报告、变现台账。
- 成片链：导演智能体蜂群编排、图生视频扩展、批量生成队列与预算熔断、合成管线升级、素材台账与失败恢复、成片驾驶舱。
