## 系统要求

- **操作系统**：Windows 10 / Windows 11（64位）
- **运行时**：无需额外安装，WebView2 随系统自带
- **磁盘空间**：约 200MB（含运行缓存）
- **AI 功能**：需用户自行配置 API Key（DeepSeek / 智谱 / 硅基流动 / Ollama 等）

## 产品简介

BISU 笔溯是一款 100% 本地离线的网文创作桌面工具，专为网文新手作者设计：

- **100% 本地离线**：所有数据存储在本地加密数据库，不上传任何服务器
- **AI 调用走用户自接 API Key**：Key 经 Argon2id 派生 + AES-256-GCM 本地加密
- **不收集任何用户数据**：正文与设定不上传 BISU 任何服务器
- **全流程创作覆盖**：从灵感、大纲、人设到章节写作、质检、发布一站式

## v0.10.6 更新内容（2026-09-27）

> 本版聚焦变现数据拉通、AI 配置体验、免费功能开放与侧边栏交互优化四大方向。

### 一、变现数据双库拉通

- **统一收入总览**：变现看板新增网文平台收入 + IP 改编收入统一汇总，全口径总收入一目了然，不再需要分别查看两个模块

### 二、AI 配置体验优化

- **密钥自动回退**：预配置模型密钥未同步时自动从历史配置中读取，减少"模型未配置"误判
- **模型测试更智能**：图像/视频模型自动使用对应测试端点，不再因端点不匹配误报"模型不可用"
- **未配置友好提示**：测试模型时密钥为空会给出明确引导，不再发送无效请求

### 三、免费功能开放

- **长篇连载免费**：长篇连载从付费功能调整为基础写作功能，免费用户可直接使用

### 四、侧边栏交互优化

- **空间切换更便捷**：项目空间列表在所有页面可见，无需返回编辑器即可切换项目
- **全部项目一览**：未选中项目时展示全部项目列表，支持快速切换、打开文件夹、移除记录
- **界面更简洁**：移除重复的最近项目区块，侧边栏布局更清爽

## v0.10.5 更新内容（2026-09-27）

> 本版聚焦 API 配置稳定性、缺陷修复、导航体验与性能优化四大方向。

### 一、API 配置稳定性增强

- **API Key 解密性能大幅提升**：优化密钥派生缓存机制，消除周期性 CPU 占用尖峰，模型列表加载与 AI 调用更流畅
- **配置异常友好提示**：API Key 解密失败时不再产生大量重复日志，改为节流提示并引导用户重新输入
- **加密错误透明化**：加密失败时明确报错，不再静默写入无效数据
- **明文 Key 内存保护**：解密后的 API Key 仅在单次调用期间临时存在，调用结束立即释放

### 二、缺陷全面修复

- **窗口托盘隐藏卡死修复**：修复窗口最小化到托盘后可能出现的界面无响应问题（旧版在特定条件下会导致 UI 线程高占用）
- **章节版本恢复功能修复**：版本时光机的「恢复」操作此前可能不生效，现已修复为真实恢复历史版本内容
- **高级编辑器保存修复**：使用高级编辑器时 Ctrl+S 不再出现旧内容覆盖新内容的问题
- **新手引导叠加修复**：首次启动时多层引导弹窗不再连续叠加弹出
- **启动日志优化**：减少启动过程中的冗余警告信息
- **账号体系兼容性提升**：新旧账号命令双轨兼容，历史版本升级无感知

### 三、侧边栏导航重构

- **七大功能分组**：导航按「创作 / 设定 / AI生产 / IP改编链 / 质检 / 市场 / 发布与收益」七大分组重组，功能定位更清晰
- **52 项功能统一管理**：所有功能入口纳入静态配置，展开收起更流畅
- **经典旧版折叠**：历史经典功能收进折叠子组，主界面更清爽
- **付费功能标识**：专业版功能带锁标识，免费功能一目了然

### 四、性能优化

- **API Key 操作提速**：密钥派生缓存消除重复计算，模型配置相关操作响应更快
- **导航渲染优化**：侧边栏数据静态化，切换页面时不再重复构建导航树
- **日志降噪**：异常日志节流输出，减少磁盘写入与性能干扰
- **并发锁优化**：密钥缓存与数据库访问分离，消除潜在死锁风险

## 核心功能

### 爆款智能体蜂群
一个项目一组各有人格的智能体，围绕同一本书共享世界设定，7 角色流水线协同产出章节初稿：选题策划 → 人设主笔 → 章节扩写 → 爽点节奏评审 → 质检 → 去 AI 味润色 → 平台合规审校。

### 全流程创作工具
- **长篇连载 / 短篇合集**：多项目管理，章节状态跟踪
- **世界观 / 角色管理 / 大纲管理**：设定一致性校验，跨章人设守卫
- **AI 创作助手**：智能续写、节奏分析、去 AI 味精修、敏感词合规检测
- **质量门控**：4 维评分（去AI味 / 爽点密度 / 情绪曲线 / 逻辑自洽），13 子项明细

### IP 改编链
从小说到剧本、条漫、视频的一站式改编管线：改编规划、分段流水线、剧本工坊、条漫工坊、视频制作、成片驾驶舱。

### 数据与市场
- **多平台排行榜**：番茄 / 起点 / 晋江 / 飞卢等平台榜单趋势
- **写作统计与目标**：字数热力图、创作目标、打卡挑战
- **变现台账**：记录各改编方向投入产出

## 安全与隐私

- 所有创作数据存储于本地 SQLite 数据库，启用 WAL 模式
- API Key 经 Argon2id（64MB 内存 / 3 轮）派生密钥后 AES-256-GCM 加密存储
- 安装包经 minisign 签名，自动更新时验签通过才安装
- 不含任何云依赖，不收集任何用户数据
