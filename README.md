## 系统要求

- **操作系统**：Windows 10 / Windows 11（64位）
- **运行时**：无需额外安装，WebView2 随系统自带
- **磁盘空间**：约 200MB（含运行缓存）
- **AI 功能**：需用户自行配置 API Key（DeepSeek / 智谱 / 硅基流动 / Ollama 等）

## 产品简介

BISU 笔溯是一款 100% 本地离线的网文创作桌面工具，专为网文新手作者设计：

- **100% 本地离线**：所有数据存储在本地加密数据库，不上传任何服务器
- **AI 调用走用户自接 API Key**：Key 经 Argon2id 派生 + AES-256-GCM 本地加密
- **不收集任何用户数据**：正文与设定不上传 BISU 任何服务器
- **全流程创作覆盖**：从灵感、大纲、人设到章节写作、质检、发布一站式

## 核心功能

### 爆款智能体蜂群
一个项目一组各有人格的智能体，围绕同一本书共享世界设定，7 角色流水线协同产出章节初稿：选题策划 → 人设主笔 → 章节扩写 → 爽点节奏评审 → 质检 → 去 AI 味润色 → 平台合规审校。

### 全流程创作工具
- **长篇连载 / 短篇合集**：多项目管理，章节状态跟踪
- **世界观 / 角色管理 / 大纲管理**：设定一致性校验，跨章人设守卫
- **AI 创作助手**：智能续写、节奏分析、去 AI 味精修、敏感词合规检测
- **质量门控**：4 维评分（去AI味 / 爽点密度 / 情绪曲线 / 逻辑自洽），13 子项明细

### IP 改编链
从小说到剧本、条漫、视频的一站式改编管线：改编规划、分段流水线、剧本工坊、条漫工坊、视频制作、成片驾驶舱。

### 数据与市场
- **多平台排行榜**：番茄 / 起点 / 晋江 / 飞卢等平台榜单趋势
- **写作统计与目标**：字数热力图、创作目标、打卡挑战
- **变现台账**：记录各改编方向投入产出

## 安全与隐私

- 所有创作数据存储于本地 SQLite 数据库，启用 WAL 模式
- API Key 经 Argon2id（64MB 内存 / 3 轮）派生密钥后 AES-256-GCM 加密存储
- 安装包经 minisign 签名，自动更新时验签通过才安装
- 不含任何云依赖，不收集任何用户数据
