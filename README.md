# BISU笔溯 - 桌面网文创作软件

BISU笔溯是一款专为网文创作者打造的桌面端AI辅助创作软件，基于Tauri v2 + React + Rust构建，提供从创作、设定、改编到发布的全链路智能写作支持。

## 核心功能

### 创作域
- **工作台**：项目总览与快速入口
- **长篇连载**：多卷多章结构化写作
- **短篇合集**：短篇作品管理
- **成片驾驶舱**：IP全链总览，小说/短剧/条漫/成片四形态数据汇总
- **改编规划**：卷章选择与创意决策，智能保留/删减建议
- **今日任务/创作目标/写作打卡**：创作进度管理

### 设定域
- 世界观、角色管理、大纲管理、时间线
- 知识库、创作记忆、网文术语、风格档案

### AI工坊
- **爆款蜂群**：多智能体协作爆款生成
- **蜂群智能体**：可配置AI智能体团队
- **RSI自我改进**：评估-反馈-策略-迭代闭环，持续优化作品质量
- 分段改编流水线、剧本工坊、条漫工坊、蜂群导演台
- 去AI味、去AI精修、AI创作、智能体中心
- 技能中心、灵感推荐、封面工作室、影视剧本、条漫漫剧

### 洞察域
- 质量门控、质量分析、读者模拟、写作教练
- 逻辑扫描、小说体检、爆款公式、排行榜
- 榜单分析、写作统计、市场情报、变现看板
- 新书评估、消痕效果报告、年度大作

### 发布与资产
- 发布中心、多平台发布、作品管理
- 素材收集箱、视频制作、视频物料工坊
- 作家品牌、变现台账

## 变更记录

### v0.10.2 (2026-09-26)

**核心改进**
- **RSI自我改进控制台闭环实现**：关联当前作品数据，新增三步爆款生成流水线（选作品→蜂群执行→RSI四维评估），无蜂群历史时自动降级为项目启发式评估，修复前后端API契约系统性不匹配
- **成片驾驶舱数据流拉通**：修复comic_list pro门控导致的"后端未就绪"误报警告，从volumes实时计算真实章节数/字数，成本沙盘错误提示修正
- **改编规划真实数据接入**：从currentProject.volumes生成真实卷章候选，调用charcard_list获取真实角色建档数，无项目时显示引导空态而非假数据
- **左侧导航重构**：按业务价值链路重排（创作→设定→AI工坊→洞察→发布→系统），移除工作流入口，合并coach/writingcoach重复入口
- **性能优化**：6个重组件懒加载（主包瘦身~645KB），9个高频API接入30s内存缓存+并发去重，4处Rust unused Result警告消除

**修复问题**
- 功能重复：移除工作流入口、合并AI教练/写作教练
- 空壳功能：RSI/成片驾驶舱/改编规划全部接入真实数据
- 数据流断裂：RSI与项目/蜂群链路打通，改编规划读取真实卷章
- 编译错误：tsc 0 error、cargo check 0 error
- 数据孤岛：RSI评估可基于项目quality_scores历史数据

## 使用方式

1. 下载对应版本安装包并安装
2. 启动BISU笔溯，创建或导入作品
3. 在工作台选择作品后，可使用各功能模块
4. AI功能需配置API密钥（设置→AI配置）

## 系统要求

- Windows 10/11 x64
- WebView2 Runtime（系统通常已自带）
- 约500MB磁盘空间
