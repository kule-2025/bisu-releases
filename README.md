# BISU 笔溯

> 网文创作全链路桌面工具 — 从萌新作者到大神作者的成长闭环

## 当前版本

**v0.10.2**

## 安装

- Windows: 下载 `BISU_0.10.2_x64-setup.exe` 运行安装
- 支持应用内无感自动更新

## 主要功能

- 作品管理：创建/编辑/删除作品，章节级定稿
- AI 辅助：多模型聚合，续写/润色/大纲/角色生成
- 排行榜：番茄/起点/晋江等多平台榜单跳转（合规模式）
- 会员体系：4档权益，许可证激活
- 云同步：Repository 抽象层，支持本地 SQLite / 未来 HTTP
- 开发者超管：用户管理/订单/日志/审计（开发者本机显示）
